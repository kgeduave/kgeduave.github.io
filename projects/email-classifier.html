EMAIL AUTOMATION

Email Classification System

An automated workflow that processes incoming emails, categorizes them, records the results, handles errors, and sends notifications to the appropriate channel.

n8n Gmail Google Sheets Slack

OVERVIEW

Automating the first steps of email processing.

Businesses can receive a large number of emails that need to be reviewed, categorized, recorded, and routed to the appropriate person or team.

I built this workflow to automate the initial processing of incoming emails and create a structured record of each message.

THE PROBLEM

Manual email processing can be repetitive.

Without an automated process, every incoming email may require someone to manually identify the message, determine its category, record it, and notify the appropriate team.

This can lead to repetitive work and makes it harder to maintain a consistent record of incoming requests.

THE WORKFLOW

From incoming email to organized record.

01

Receive Email

A new email triggers the workflow.

02

Check for Duplicates

The workflow checks whether the message has already been processed.

03

Record Message

Relevant email information is stored in Google Sheets.

04

Classify

The email is categorized based on its content.

05

Update Record

The classification is written back to the tracking sheet.

06

Notify

A notification is sent through Slack.

CLASSIFICATION

Organizing emails into useful categories.

The workflow separates incoming messages into predefined categories so that they can be handled more efficiently.

Billing

Questions and requests related to billing, payments, or charges.

Technical Support

Technical issues and troubleshooting requests.

Account Management

Account-related questions and requests.

Sales

Sales inquiries and potential customer requests.

Fallback

Messages that do not clearly fit another category.

ERROR HANDLING

Designing for failures, not just successful runs.

The workflow includes a separate error-handling path for classification failures. Instead of silently losing a message when an error occurs, the workflow records the failure for review.

This makes troubleshooting easier and provides a record of messages that require additional attention.

KEY FEATURES

What the workflow handles.

Automated Trigger

New Gmail messages automatically start the workflow.

Duplicate Detection

Previously processed messages can be identified using their message ID.

Centralized Tracking

Email information and classification results are stored in Google Sheets.

Error Logging

Classification failures are recorded separately for troubleshooting.

Slack Notifications

Processed messages can trigger notifications for the relevant team.

TOOLS

Technologies used.

RESULT

A repeatable process for incoming email.

The finished workflow turns incoming emails into structured records, applies a consistent classification process, handles duplicate and error scenarios, and provides notifications for visibility.

The project demonstrates how workflow automation can be used to reduce repetitive administrative tasks while maintaining a clear record of what happened during each processing step.
